Roadmap

What's next

The near-term lanes we are executing. Core wallet, DeFi, and the Telegram Mini App already ship today — see Delivered.

Fiat off-ramp (sell)

In progress

Selling crypto to fiat directly from the wallet, on top of the same gateway that already powers Buy Crypto. Identity verification and payouts stay on the provider's side.

Full Telegram parity

In progress

Bringing the remaining earn/rewards and financial lanes in the Telegram Mini App to full parity with the web wallet.

Desktop app

In progress

A desktop shell (Tauri) builds today; hardening it into a publicly shipped release is in progress.

Open-source DEX modules

Planned

Once the DEX adapters stabilize further, publish them as reusable packages in a public repository so integrators can embed and improve them.

NFT mint & marketplace

Planned

Native in-wallet NFT minting and marketplace flows, building on the existing NFT view/send support.

Additional platforms

Planned

Native mobile shells — and a browser extension if needed — once the current security and audit checklist is cleared. The same protections and flows carry over to every device.
